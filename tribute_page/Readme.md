# Shahid Ahmad Ibrahim Zakzaky — Tribute Website

A dignified, responsive, and accessible tribute page dedicated to the life, legacy, and memory of Shahid Ahmad Ibrahim Zakzaky (Fa'iz). This project was built as part of the **OASIS INFOBYTE Web Development & Designing Internship — Level 2, Task 2: Tribute Page**.

## Project Description

This website serves as a digital memorial that respectfully documents the life, education, character, community service, and enduring legacy of Ahmad Zakzaky. It presents a balanced, historically responsible narrative through a polished single-page experience with rich typography, subtle animations, and full light/dark theme support.

The design communicates **dignity, memory, knowledge, service, courage, and legacy** — without sensationalism or political bias.

## Features

- **Responsive Design** — Works flawlessly from 320px to 1920px+
- **Dark / Light Mode** — Smooth theme switching with system preference detection and `localStorage` persistence
- **Biography** — 5 detailed, original paragraphs covering early life, education, character, youth service, and final chapter
- **Timeline** — Vertical chronological timeline with scroll-reveal animations
- **Legacy** — Four visually distinct legacy cards highlighting knowledge, compassion, youth empowerment, and sacrifice
- **Gallery** — Tasteful image grid with lazy loading, captions, and source credits
- **External Sources** — Curated source cards with external links (biographical, human-rights, news, image archives)
- **Accessibility** — Semantic HTML, keyboard navigation, ARIA labels, focus states, reduced-motion support
- **Smooth Navigation** — Sticky nav, mobile hamburger menu, active section indicator, back-to-top button
- **SEO** — Meaningful `<title>`, meta description, Open Graph tags, and semantic heading structure

## Technologies

- **HTML5** — Semantic markup
- **CSS3** — Custom properties (themes), Flexbox, Grid, clamp() typography, animations
- **Vanilla JavaScript** — Theme toggle, mobile nav, scroll spy, reveal animations, back-to-top

No frameworks, no libraries, no build tools — just clean, self-contained code.
