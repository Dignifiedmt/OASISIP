# AuthFlow

AuthFlow is a responsive React login and registration experience for the OASIS INFOBYTE internship. It includes client-side validation, local session persistence, password visibility controls, and an authenticated dashboard.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Note

This is a frontend demonstration. User accounts and passwords are stored in browser `localStorage` and are not suitable for production authentication.
